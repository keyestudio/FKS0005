# 3. Gamepad-Montage

![Img](./media/shoubin.png)

## 3.1 Installation
Benötigte Teile:

![Img](./media/z0001.png)

Installieren Sie diese Nylon pillars auf der Steuerplatine.

![Img](./media/z0002.png)

So:

![Img](./media/z0003.png)

Und dann montieren Sie die obere Acrylplatte mit vier M3*6 Schrauben an der Steuerplatine.

![Img](./media/z0004.png)

So:

![Img](./media/z0005.png)

Drehen Sie die Platine um und kleben Sie das 3M doppelseitige Klebeband in das gelbe Feld auf der Rückseite der Steuerplatine.

![Img](./media/z0006.png)

So:

![Img](./media/z0007.png)

Schalten Sie den Schalter am Batteriehalter auf „ON“. Die Seite mit dem Schalter sollte beim Anbringen zum Klebeband zeigen (**Achten Sie auf die Richtung und Position des Batteriekastens. Bitte richten Sie ihn genau an der gelben Linie aus; andernfalls könnten die folgenden Acrylplatten blockiert werden**).

![Img](./media/z0008.png)

Und dann verbinden Sie das Kabel des Batteriehalters mit der Steuerplatine. So:

![Img](./media/z0009.png)

Montieren Sie nun die beiden unteren Acrylplatten mit vier M3*6 Schrauben am Gamepad.

![Img](./media/z0010.png)

Herzlichen Glückwunsch! Installation abgeschlossen!

![Img](./media/z0011.png)
