## Fehlerbehebung

1\. Nach dem Hochladen des Codes zeigt die 5x5-Matrix des micro:bit ein weinendes Gesicht an und es werden Fehlermeldungen in scrollender Weise angezeigt.

2\. Wenn der hochgeladene Code versehentlich Zeichen hinzugefügt oder gelöscht hat, können Sie dies gemäß den Anweisungen in der Shell überprüfen.

![Img](./media/g002.png)

3\. Wenn der hochgeladene Code Bibliotheksdateien von Drittanbietern enthält, überprüfen Sie zuerst, ob die entsprechenden Bibliotheken auf das micro:bit-Board hochgeladen wurden. Informationen zum Importieren von Bibliotheken finden Sie unter „**5.1.4 Code hochladen**“.

4\. Nach dem Hochladen des Codes werden keine Daten gedruckt. Sie müssen zuerst auf "![Img](./media/t027.png)" klicken und dann die Reset-Taste auf der Rückseite des Micro:bit-Boards drücken, woraufhin die Daten normal gedruckt werden.

![Img](./media/g001.png)

5\. Die MicroPython-Firmware geht nach dem Brennen des MakeCode-Codes verloren, und die Shell gibt die Fehlermeldungen aus:

![Img](./media/g000.png)

Zu diesem Zeitpunkt müssen Sie die Firmware erneut brennen, siehe **5.2.3 MicroPython-Firmware brennen (Wichtig)**.
