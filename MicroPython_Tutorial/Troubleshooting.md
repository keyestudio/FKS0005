## Solución de problemas

1\. Después de cargar el código, la matriz de 5x5 de micro:bit muestra una cara triste y se desplazarán mensajes de error.

2\. Si el código cargado tiene caracteres añadidos o eliminados por error, puede verificarlo según las indicaciones en el shell.

![Img](./media/g002.png)

3\. Si el código cargado contiene archivos de biblioteca de terceros, primero verifique si las bibliotecas correspondientes se han cargado en la placa micro:bit. Para saber cómo importar una biblioteca, consulte "**5.1.4 Cargar código**".

4\. Después de cargar el código, no se imprimen datos. Debe hacer clic en "![Img](./media/t027.png)" primero, y luego presionar el botón de reinicio en la parte posterior de la placa Micro:bit, después de lo cual los datos se imprimirán normalmente.

![Img](./media/g001.png)

5\. El firmware de micropython se perderá después de grabar el código de Makecode, y el shell imprimirá los mensajes de error:

![Img](./media/g000.png)

En este momento, debe grabar el firmware nuevamente, consultando **5.2.3 Grabar firmware de Micropython (Importante)**.
